# Changelog

## v1.0.0

Initial public release.

- Ubuntu 24.04 XFCE desktop over XRDP
- German locale and keyboard defaults
- Default first account renamed to `admin`
- Multi-user admin/standard account model
- Resettable guest/standard profiles with XRDP session data preserved
- RDP client-drive redirection via FUSE
- RDP audio playback and microphone support
- One bottom XFCE panel, blue background and automatic icon arrangement
- Firefox, Chrome, LibreOffice, GIMP, Xournal++, PDF Arranger
- GIMP as image default, Xournal++ as PDF default
- CUPS with per-user network-printer mapping and persistent golden profiles
- GPU/VAAPI passthrough support
- Unraid DockerMan template with editable settings
- GitHub Actions workflow for GHCR images
